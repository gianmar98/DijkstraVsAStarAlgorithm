This project was built witgh Python using Pygame for my last class of my undergraduate degree. The class was CS 530, an AI oriented class.

Way to use:
- main.py is the file to run
- you will see a menu of 4 potential Labyrinths and which you can click options 1-4
- when clicking it, you will see the chosen map where the orange endpoint is the starting point and the green is the goal endpoint

  <img width="300" height="300" alt="secondLab" src="https://github.com/user-attachments/assets/4efc21fa-4f64-45b6-b488-d32fec1fa789" />

- when clicking space bar, the A* algorithm will visually show how it looks for the green endpoint while times how long it takes to find it
- When done, algorithm will show the path it found and in the terminal the time it took to find it will be shown

- by closing that tab on the red (x) on that screen, you will see the next screen for the other algorithm (Dijkstra) and the same process of running it will be applied

- This will provide both a visual and time representation of the way different path finding alrogithms work
